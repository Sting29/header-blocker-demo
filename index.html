CSS demo

A sticky header that never changes color

Scroll down. Three sections, three colors, no scroll listeners.

What you are looking at

The header at the top of the screen has no background. It is fixed in place and fully transparent, and it was never given a color.

What changes is the box behind it. Each section starts with a blocker: an empty element, as tall as the header, filled with that section's color.

How the handoff works

A sticky element follows you only while its parent is on screen. The blocker in the first section rides under the header, then leaves together with that section.

The next section's blocker is already waiting at the edge. It takes over in the same frame, so the header looks like it changed color.

No scroll position is read and no class is toggled. The browser does it on every frame.

What it costs

A blocker needs a place to sit when the page is scrolled to the top. That is an empty strip, as tall as the header, at the start of every section.

If a hero has a deep curve, or an image that runs to the very top edge, there is nowhere to hide it.

Give blockers z-index: 1 and keep your own positioned content at auto. A positioned element later in the DOM with a higher index would paint over the blocker.

Try it on this page

  • No blockers: the words slide straight under the header text.
  • Blockers: the header looks solid, and the color switches at each section edge.
  • X-ray: draws the blockers as dashed boxes and outlines the header in blue.

Recap

  • The header is position: fixed and transparent.
  • Each section has one blocker as its first child, position: sticky with top: 0.
  • Blocker height equals header height. Blocker color equals section color.

The header effect is pure CSS. The bottom bar is the only script on this page.
